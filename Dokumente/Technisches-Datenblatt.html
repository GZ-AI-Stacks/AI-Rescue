AI.-Ready Rescue — USB-Datenrettungssoftware
Gerd Zimmermann / GZ-AI.-Stacks
Stand: 29.03.2026

Produktinformationen

Produktname AI.-Ready Rescue
Version 1.0
Kategorie Datenrettungs- und Wiederherstellungssoftware
Beschreibung Spezialisierte Datenrettungssoftware für USB-Speichermedien mit Quick-Scan und Deep-Scan (File Carving) zur Wiederherstellung gelöschter oder beschädigter Dateien.
Hersteller Gerd Zimmermann / GZ-AI.-Stacks
Website https://gz-ai-stacks.de/

Systemanforderungen

Betriebssystem Microsoft Windows 7, 8, 8.1, 10, 11 (32-Bit und 64-Bit)
Laufzeitumgebung .NET Framework 4.x (ab Version 4.0)
Arbeitsspeicher min. 512 MB RAM (empfohlen: 2 GB+)
Festplattenspeicher min. 10 MB freier Speicherplatz
Bildschirmauflösung min. 1024 × 768 Pixel
Dateigröße ca. 1–3 MB
Installation Keine Installation erforderlich — portabel (USB-Stick fähig)
Internetverbindung Nicht erforderlich
Admin-Rechte Erforderlich (für Low-Level-Zugriff auf Datenträger / Raw Disk Access)

Scan-Modi

Quick-Scan

  • Durchsucht Papierkorb und versteckte Dateien
  • Analyse der Dateisystem-Strukturen (FAT32 / NTFS)
  • Schnelle Erkennung kürzlich gelöschter Dateien
  • Niedrige Systembelastung

Deep-Scan (File Carving)

  • Sektorweises Durchsuchen des gesamten Datenträgers
  • Signaturbasierte Dateierkennung unabhängig vom Dateisystem
  • Wiederherstellung auch bei beschädigter Partitionstabelle

Unterstützte Dateitypen (File Carving)

JPG PNG PDF ZIP MP3 MP4 AVI DOC und weitere

Unterstützte Dateisysteme

FAT32 NTFS

Funktionen

  • Automatische Erkennung angeschlossener USB-Speichermedien
  • Zwei-Stufen-Scan: Quick-Scan für schnelle Ergebnisse, Deep-Scan für gründliche Analyse
  • Vorschau wiederherstellbarer Dateien vor der Rettung
  • Frei wählbarer Zielordner für wiederhergestellte Dateien
  • Fortschrittsanzeige mit geschätzter Restzeit
  • Dark-Theme-Benutzeroberfläche

Portabilität

AI.-Ready Rescue ist vollständig portabel. Die Anwendung kann ohne Installation direkt von einem USB-Stick oder einem beliebigen Speichermedium ausgeführt werden. Es werden keine Einträge in der Windows-Registry vorgenommen und keine Systemdateien verändert.

Datenschutz und Sicherheit

  • Keine Internetverbindung erforderlich
  • Keine Datenerhebung, keine Telemetrie, kein Tracking
  • Sämtliche Verarbeitung erfolgt ausschließlich lokal
  • Keine Cloud-Anbindung
  • Keine Daten verlassen das Gerät des Nutzers

Barrierefreiheit

  • WCAG 2.1 Level AA+ konform
  • Vollständige Tastaturbedienung
  • Screenreader-kompatibel
  • Kontraststarkes Dark Theme

Wichtiger Hinweis

Eine erfolgreiche Datenrettung kann nicht garantiert werden. Der Erfolg hängt vom Zustand des Datenträgers, dem Grad der Überschreibung und weiteren Faktoren ab. Die Nutzung erfolgt auf eigene Gefahr des Nutzers.
